# yp

터미널에서 유튜브를 검색하고 오디오만 재생합니다. 브라우저가 필요 없습니다.

> **Keywords:** youtube cli, youtube audio, terminal music player, youtube terminal, macos audio player, yt-dlp cli, mpv youtube, background music terminal

```
yp "lofi hip hop"
```

```
? 재생할 영상을 선택하세요:
❯ Lofi Hip Hop Radio 📚 - Beats to Relax/Study to [1:12:34]
  lofi hip hop radio 🎧 - beats to sleep/chill to [24:00:00]
  Lofi Girl - Study Mix 2024 [2:08:45]
  ...
```

## 데모

![yp 데모](assets/demo.gif)

검색 → 화살표로 선택 → 전체화면 카드로 재생 → `q`로 흔적 없이 복귀.

## 설치

```bash
brew install cleanhyune/yp/yp
```

## 사용법

```bash
yp "검색어"           # 검색 후 화살표로 선택, 오디오 재생
yp                    # 최근 재생 목록에서 바로 고르기 (yp -r / yp --recent 도 동일)
yp -c 조강현          # 채널의 최신 영상 목록에서 고르기. 자동재생은 그 채널 영상을 최신순으로 이어감 (@핸들·채널 URL도 가능)
```

재생을 시작하면 화면 전체가 카드형 UI로 바뀌어 제목·채널·진행 표시줄·볼륨·자동재생
상태를 한눈에 보여주고, `q`로 종료하면 흔적 없이 원래 터미널로 돌아옵니다.

재생 중 키보드 컨트롤:

| 키 | 동작 |
|---|---|
| `Space` | 일시정지 / 재개 |
| `←` / `→` | 5초 앞뒤 탐색 |
| `9` / `0` | 볼륨 조절 |
| `n` | 다음 자동재생 영상으로 바로 건너뛰기 |
| `p` | 이전에 듣던 영상으로 돌아가기 (처음부터 재생). 되돌아간 뒤 `n`을 누르면 떠났던 그 영상으로 복귀 |
| `q` | 종료 후 재검색 |
| `g` | 시간 입력 후 해당 구간으로 이동 (예: `0710` → 7:10, `012930` → 1:29:30) |
| `t` | 현재 영상의 댓글을 같은 화면에서 보기. `j`/`k`로 댓글 사이를 이동하고(`Space`는 화면 단위), 마지막 댓글에서 `j`를 누르면 다음 페이지를 이어서 불러옴. `Enter`로 선택한 댓글의 답글 보기, `q`/`←`로 되돌아가기. `s`로 인기순/최신순 전환, `q`로 닫기 |
| `a` | 자동재생 켜기/끄기 (기본값: 켜짐, 다음 실행에도 유지) |

댓글 목록에는 각 댓글의 좋아요 수와 답글 수, 작성 시기가 유튜브 표기 그대로(`좋아요 31만 | 답글 962 | 1년 전`) 붙습니다. `답글 N`이 있는 댓글에서 `Enter`를 누르면 그 댓글을 위에 고정한 채 아래에 답글이 펼쳐지고, 마지막 답글에서 `j`를 누르면 다음 답글 페이지를 이어서 불러옵니다. `q`나 `←`로 돌아오면 원래 보던 자리 그대로입니다. 기본 정렬은 인기순이고 `s`로 최신순과 오갈 수 있습니다.

영상이 끝까지 재생되면 유튜브의 "연관 동영상" 중 같은 채널의 영상을 우선해 자동으로 이어서 재생합니다. 다음 영상이 정해지면 카드 안에 "↳ 제목 · 채널"이 표시되고, `n`으로 바로 넘어갈 수 있습니다. 다음 영상은 재생 중에 스트림 주소까지 미리 풀어두기 때문에, 자동재생이나 `n`으로 넘어갈 때 끊기는 시간이 거의 없습니다. `a`로 끄거나 `q`로 직접 종료하면 새 검색어 입력 프롬프트로 돌아옵니다. `Enter`만 누르면 종료.

30초 이상 듣다가 중간에 끈 영상은 다음에 다시 재생할 때 그 위치부터 이어서 재생합니다. 최근 재생 20개는 `~/.config/yp/history.json`에 남고, `yp`를 검색어 없이 실행하면 그 목록에서 바로 고를 수 있습니다.

## 요구 사항

- macOS
- [Homebrew](https://brew.sh)

## 재생이 안 될 때

`Sign in to confirm you're not a bot` 오류로 재생이 실패하면, YouTube가 해당
네트워크에 봇 인증을 요구하기 시작한 것입니다. 이 경우 yp는 마지막 수단으로 **Chrome에
저장된 쿠키를 읽어** 다시 시도할 수 있습니다. 이 기능은 기본으로 꺼져 있고, 첫 재생 직전에
한 번만 허용 여부를 묻습니다. 허용하면 Chrome으로 YouTube에 한 번이라도 접속해 둔 상태라면
별도 설정 없이 재생이 이어집니다. 나중에 바꾸려면 `~/.config/yp/state.json`의 `cookies`
값을 `true`/`false`로 고치거나 키를 지우면 다시 묻습니다.

- 쿠키를 쓰는 시도가 성공하면 그 방식을 기억해 다음 영상부터는 바로 그 경로로 시작합니다
  (실패하는 시도를 매번 반복하지 않기 위한 것입니다).
- 다만 **하루에 한 번은 원래의 빠른 경로를 다시 시도**합니다. YouTube가 차단을 풀면
  쿠키를 쓰지 않는 경로로 저절로 되돌아갑니다. 차단이 그대로면 이때 약 6초를 더 씁니다.
- 로그인한 상태의 Chrome이라면 그 계정 쿠키가 요청에 함께 실립니다. 즉 yp로 들은 영상이
  YouTube 시청 기록에 남을 수 있습니다.
- Chrome이 없거나 쿠키를 읽지 못하면 그 시도만 실패하고, yp는 익명 경로로 되돌아갑니다.

자동재생이나 댓글이 이유 없이 멈추면 `YP_DEBUG=1 yp "검색어"`로 실행하세요. 내부에서
삼킨 오류가 `~/.config/yp/debug.log`에 쌓입니다 (다른 값을 주면 그 경로에 씁니다).
